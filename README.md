# AI Automation Society theme for Claude

A free theme for the Claude desktop app, a gift for members of the AI Automation Society community.

It turns the background of your Claude chats into the community card: the glowing sky that slowly moves, the globe logo, the name, and the pine ridge at the bottom. The chat panels get a light dark film so your text stays easy to read. Dark mode only.

## Celebrations

Each time Claude finishes a step of its task list, glowing confetti blows over the screen. When the whole task is done, big blue fireworks go off, with a confetti finale.

Want to see them right now? Type `/ais-confetti` or `/ais-fireworks` in a chat.

## Install

In a terminal, run:

```bash
claude plugin install ai-automation-society-theme --marketplace Mike-AIConsultant/ai-automation-society-theme
```

Or inside a Claude Code terminal session, type `/plugin install ai-automation-society-theme --marketplace Mike-AIConsultant/ai-automation-society-theme`, answer `y` to add the marketplace, then press Enter.

In the Claude desktop app: click + next to the prompt box, then Plugins, Add marketplace, type `Mike-AIConsultant/ai-automation-society-theme`, then Add plugin.

Start a new chat and the background appears.

## Remove

```bash
claude plugin uninstall ai-automation-society-theme
```
